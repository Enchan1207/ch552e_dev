# CH552Eを使ってみる

## Overview

CH552Eの色々なペリフェラルで遊ぶ

## Requirements

- [SDCC](https://sdcc.sourceforge.net/)
- プログラマ (ローカルでは [wchisp](https://github.com/ch32-rs/wchisp) を利用)

## Usage

構成

```sh
cmake --preset target
```

ビルド

```sh
cmake --build --preset target 
```
